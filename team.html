Step 1 · Generate Your Card

Fill this in and click the button. It writes the HTML for your team card, ready to paste into this file.

Why doesn't this just submit? Because there's nothing to submit to. This site is only HTML and CSS — files a browser opens directly. There's no server running behind it to receive your details and no database to store them.

That's not a limitation we forgot to fix; it's what "static site" means, and it's how GitHub Pages works. Saving your data would require a backend, which is a whole other workshop. Here, Git is the storage — you save your details by committing them, which is exactly the skill we're after.

Step 2 · Get It Onto GitHub

This is the part that matters. Run each command on its own and read what it prints back.

  1. Get the project, if you haven't already 
    git clone https://github.com/RCNile/AI-Academy-Using-Github.git
cd AI-Academy-Using-Github
  2. Make your own branch. Put your name in it, so it's obvious whose branch it is. 
    git checkout -b feature/add-jane-smith
    -b means "create this branch and switch to it".
  3. Open team.html in your text editor, find <div class="team-grid">, and paste your card in just after it. Save the file.
  4. Check your work in the browser. Open team.html and confirm your card looks right before you commit anything.
  5. See what Git noticed 
    git status    # which files changed
git diff      # exactly which lines changed
    git diff is worth getting comfortable with — it's what reviewers read. Press q to exit.
  6. Stage and commit 
    git add team.html
git commit -m "Add Jane Smith to team page"
    Use your own name in the message. Finish the sentence "if applied, this commit will…".
  7. Push your branch to GitHub 
    git push origin feature/add-jane-smith
  8. Open the pull request. Git prints a link — open it, write a sentence about what you did, and click Create pull request.
That's the whole job You've just used the same workflow that ships production software. The commands don't get more advanced than this — the rest is practice and learning what to do when something goes wrong.
